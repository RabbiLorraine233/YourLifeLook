# YourLifeLook# 人生概览 · A Life in Chapters

一份装帧考究的个人编年史。以编辑杂志 / 极简精装书的气质，把你的人生关键节点，沿一条优雅的时间轴静静展开。

> 「把每一段日子，都过成可以收藏的章节。」

![预览](screenshots/hero.png)

---

## ✨ 特性

- **扉页信息** — 填写姓名、出生日期、人生主题 / 箴言，作为整张图的标题。
- **人生节点** — 添加关键时刻，记录时间（可只填年份，也可精确到年月日）、事件标题、一句话描述。
- **自动年龄** — 根据出生日期自动推算每个事件发生时的年龄（如「23 岁」），排版低调精致。
- **自动排序** — 节点按时间自动排列，沿竖向时间轴依次展开；末尾有一个「今」的呼吸式收束。
- **分类与配色** — 学业 / 事业 / 感情 / 旅行 / 家庭，各有沉稳的点缀色。
- **保存为长图** — 一键导出高清 PNG，排版完整精致，适合打印或收藏。
- **本地保存** — 数据存在浏览器本地，刷新不丢失。
- **格调可调** — 象牙白 / 墨黑双主题、多种衬线标题字体、点缀色、纸张噪点、节点间距，皆可微调。
- **响应式** — 桌面与手机均有适配布局。

## 🚀 使用方法

### 在线浏览
打开 [`人生概览-发布版.html`](人生概览-发布版.html) 即可使用 —— 这是一个自包含的单文件版本，是发布与分享的推荐入口。

### 本地运行
直接用浏览器打开 `人生概览-发布版.html` 即可，无需任何构建步骤。
（需联网以加载字体与运行库。）

### 部署到 GitHub Pages
1. 将本仓库推送到 GitHub。
2. 进入 **Settings → Pages**，Source 选择 `main` 分支、根目录 `/`。
3. 访问 `https://<你的用户名>.github.io/<仓库名>/人生概览-发布版.html`。

> 提示：如希望访问根地址即打开，可把 `人生概览-发布版.html` 复制 / 重命名为 `index.html`。

## 📁 文件说明

| 文件 | 说明 |
| --- | --- |
| `人生概览-发布版.html` | **单文件版**，所有脚本已内联 —— 发布只需这一个文件 |
| `Life Overview.html` | 开发用主文件（引用下方各脚本） |
| `chronicle.jsx` | React 应用主体：扉页、时间轴、增删改、年龄计算 |
| `canvas-export.js` | 高清长图 PNG 导出（直接绘制到 canvas） |
| `tweaks-panel.jsx` | 「格调」调节面板组件 |
| `screenshots/` | 预览图 |

## 🛠 技术

纯前端，零构建。React（CDN）+ 浏览器内 Babel 转译 JSX，原生 Canvas 绘制导出图片，`localStorage` 持久化。
字体：Cormorant Garamond / Playfair Display / EB Garamond + Noto Serif/Sans SC。
